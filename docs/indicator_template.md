# 单指标说明文档模板(Phase 1 基线)

> 用途:Phase 2 转换流水线「单指标文档自动生成」(Task 2.5)统一套用本模板。
> 固定小节与「思维导图·单指标管理」逐项对应,生成器与人工编写的文档都必须
> **保持小节标题与顺序不变**(便于解析与登记)。
>
> 约定:
> - 每个已使用指标(all.txt 中一行)一份文档,路径建议 `docs/indicators/{指标名称}.md`(以 Phase 2 实际目录为准);
> - 每一小节都必须出现;该指标不产生某类信号的,写「不适用」并说明原因,不得删节;
> - 公式/参数口径与项目 `data/profit_mining/features.py`、`/home/tdxback/通达信py脚本/tq_confirm_top10.py` 一致;
> - 占位符 `{...}` 由生成器替换为真实内容。

## 指标说明

{一句话说明该指标衡量什么、在本系统中的用途,以及它参与的组合/信号(编号可列)}

## 原始公式

{通达信/TDX 侧原始公式(如有)。无 TDX 原版公式时,给出指标定义式。}

## 转换逻辑

{TDX 公式 → Python(pandas)逐行移植说明,至少覆盖:
- 内置函数映射:REF→shift、HHV→rolling.max、LLV→rolling.min、MA→rolling.mean、
  EMA→ewm(span=n, adjust=False)、SMA(X,N,M)→ewm(alpha=M/N, adjust=False)、
  CROSS→上穿判断、BARSLAST→距上次为真 bar 数;
- 口径差异:SMA 递归口径、NaN/停牌前向填充、涨跌停幅度 p(300/301 开头 0.20,其余 0.10)、
  复权方式(dividend_type='none' 不复权)、单位(成交额万元/价格元);
- 已知简化或近似处理。}

{该指标触发买入/做多需满足的布尔条件;常与其他子条件组合(AND)构成信号,列出搭配组合。
不产生买入信号的写「不适用」及原因。}

## 卖出信号

{该指标触发卖出/看空的布尔条件;不产生卖出信号的写「不适用」及原因。}

## 适用周期

{日线/分钟级/周线;大盘或个股;适用股票范围(如沪深A股主板+创业板,排除科创板/北交所/ST)与市场状态。}

{信号不成立/失效的边界条件,至少考虑:

- 涨跌停无法成交;

## 填写示例:极限抄底

```markdown
# 极限抄底(Extreme Bottom Fishing)

- 类别:中文组合指标
- 出处:/home/tdxback/通达信py脚本/tq_confirm_top10.py:333-341(与 data/profit_mining/features.py 同口径)
- 状态:已转换
- 登记日期:2026-09-26

## 指标说明

「极限抄底」是六脉缠论 57 信号体系中最常用的抄底子条件:股价深度超跌(20 日跌幅 ≥15%
或 60 日跌幅 ≥25%)且 RSI6 极度超卖(≤20)后,出现止跌 K 线(阳线带长下影,或多方占优
且非跌停)或缩量企稳(量缩至 5 日均量 70% 以下且不再下跌)。它是 TQ01/TQ03/TQ04/TQ05/
TQ08/TQ11/TQ15/TQ20/TQ21/TQ31/TQ38/TQ41/TQ47/TQ50 等买入组合的组成部分(与主力参与、
大盘空头、火箭信号、威科夫B4强势杆、做多权重、资金强度等子条件 AND 组合)。

## 原始公式

极限跌   = (CLOSE/HHV(CLOSE,20)-1)*100 <= -15 OR (CLOSE/HHV(CLOSE,60)-1)*100 <= -25
RSI6     = SMA(MAX(CLOSE-REF(CLOSE,1),0),6,1) / SMA(ABS(CLOSE-REF(CLOSE,1)),6,1) * 100
下影长   = (CLOSE-LOW) / (HIGH-LOW+ε) > 0.5
止跌K    = (阳线 AND 下影长) OR (多方占比>0.7 AND NOT 跌停)
缩量企稳 = VOL < MA(VOL,5)*0.7 AND CLOSE >= REF(CLOSE,1)
极限抄底 = 极限跌 AND RSI6 <= 20 AND (止跌K OR 缩量企稳)

## 转换逻辑

- 跌幅20 = (c / _HHV(c,20) - 1) * 100;跌幅60 = (c / _HHV(c,60) - 1) * 100;
  极限跌 = (跌幅20 <= -15) | (跌幅60 <= -25)。HHV → c.rolling(n, min_periods=1).max()。
- RSI6:TDX SMA(X,N,1) 为递归均值,等价于 pandas ewm(alpha=1/N, adjust=False).mean();
  d = c.diff(),_RSI(c,6) = _SMA(d.clip(lower=0),6,1) / (_SMA(d.abs(),6,1) + 1e-9) * 100。
- 止跌K:阳线 = c > o;下影长 = (c-l)/rng > 0.5(rng = h-l+1e-9);多方占比 = (c-l)/rng;
  跌停 = (c <= lc*(1-p)*1.01) & (c < lc),lc=REF(close,1)。
- 缩量企稳:v < vma5*0.7 且 ~价跌(价跌 = c < lc);vma5 = MA(v,5)。
- 口径:不复权(dividend_type='none');p 由代码前缀决定(300/301 开头 0.20,其余 0.10);
  停牌日价量前向填充,信号近似中性。

## 参数说明

### 固定参数

| 参数 | 含义 | 值 | 备注 |
|------|------|----|------|
| RSI 周期 | RSI6 计算窗口 | 6 | 与 features.py 一致 |
| 跌幅窗口 | HHV 回看窗口 | 20 / 60 日 | 两个窗口任一满足即「极限跌」 |
| 跌幅阈值 | 跌幅触发线 | -15% / -25% | 20 日 ≥15% 或 60 日 ≥25% |
| RSI 阈值 | 超卖判定线 | 20 | rsi6 <= 20 |
| 下影占比 | 止跌K下影线要求 | 0.5 | (c-l)/(h-l) > 0.5 |
| 多方占比 | 非跌停止跌要求 | 0.7 | (c-l)/(h-l) > 0.7 |
| 缩量系数 | 缩量企稳量能要求 | 0.7 | v < vma5*0.7 |
| 涨跌停幅度 p | 按板块区分 | 0.20 / 0.10 | 300/301 开头 0.20,其余 0.10 |

### 可调整参数

| 参数 | 含义 | 默认值 | 建议范围 | 备注 |
|------|------|--------|----------|------|
| RSI 周期 | RSI 计算窗口 | 6 | 6~14 | 周期越短越敏感 |
| 跌幅窗口/阈值 | 超跌定义 | 20日-15%、60日-25% | 10~30日、-10%~-30% | 熊市可放宽窗口 |
| RSI 阈值 | 超卖判定线 | 20 | 15~30 | 阈值越低信号越少 |
| 缩量系数 | 企稳量能要求 | 0.7 | 0.5~0.9 | 越小要求越苛刻 |

## 买入信号

极限抄底为真(最新一根日K)时构成买入候选子条件,必须与其他子条件 AND 组合才成为完整
信号,例如:TQ01 极限抄底+主力参与+大盘空头、TQ04 极限抄底+威科夫B4强势杆+波动率大于5、
TQ38 价涨量增+极限抄底+做多权重大于1。单独命中不作为买入信号。

## 卖出信号

不适用(纯买入侧超跌反弹子条件,不产生卖出/做空信号)。

## 适用周期

日线(盘后运行口径,信号为最新一根日K状态);沪深A股主板+中小板+创业板(排除科创板
688/689、北交所、ETF/基金、ST);停牌期价量前向填充,信号近似中性。

## 失效条件

- 日K 不足 250 根(MIN_BARS)的次新股/长期停牌股直接跳过;
- 上证指数数据缺失时,含「大盘空头」的组合(如 TQ01/TQ05/TQ15)本次不触发;
- 涨跌停无法成交,命中后需自行核对流动性与可成交性;
- 盘中运行时最后一根K未收盘,信号随行情变化,以收盘后结果为准;
- 无未来函数:所有输入仅用当日及以前数据。
```
