## 一、功能概述

在交易时段内实时监控 57 个「六脉缠论」信号,盘中每 60 秒轮询候选池个股,信号由「未触发 → 触发」的瞬间即向客户端发预警(`tq_alert_top10.py:6-19`):

1. **启动扫描**:全市场取 300 根日K(与盘后扫描 `tq_confirm_top10.py` 同取数口径,约 30~90 分钟);启动时已触发的信号立即发一轮「启动提醒」,同时按「近触发」规则构建候选池,盘中只轮询候选池个股(较全市场轮询大幅减少取数量);
2. **盘中轮询**:候选池分批取最近 3 根日K(含今日盘中实时 bar),与启动时的 300 根历史缓存按日期合并后重算信号——保证 MA233 等长周期指标预热不受影响,信号口径与盘后扫描一致;
3. **去重**:按(日期, 代码, 信号号)内存集合去重,每信号每日只提醒一次,跨日自动重置;
4. **非交易时段自动休眠**,支持 Ctrl+C 优雅退出(finally 中 `tq.close()`)。

### 3.3 信号口径要点

出处:`tq_alert_top10.py:21-33`。

1. 信号 1~50 为「最新一根日K」的状态型信号,组内各子条件**同日全部成立**即触发;盘中最后一根K为当日实时 bar(未收盘),**提醒后可能随行情回退,属正常现象**;
2. 信号 51~57 以「**组合11**」为事件前提:组合11 = 最近 4 个交易日(含今日)内出现过**缠论买点**(一买/二买/强二买)且出现过**六脉六红**(六维全红),两信号不必同日(`tq_confirm_top10.py:558-573`);
3. 复权:`dividend_type='none'`(不复权);
4. 涨跌停幅度 p:300/301 开头代码 0.20,其余 0.10;
5. 大盘空头 = 上证指数 999999.SH 最新一根K close<MA20 且 MA20<MA60;大盘多头 = close>MA20 且 MA20>MA60(供卖出信号 TQ52 使用);
6. 停牌缺口:fill_data=True 前向填充;涨停板当日无法买入,下单前请自行核对可成交性。

## 四、轮询机制

### 4.1 配置项

出处:`tq_alert_top10.py:84-88`(取值)与 `tq_alert_top10.py:46-54`(文件头说明)。

| 配置项 | 默认值 | 说明 |
|--------|-------:|------|
| `POLL_SECONDS` | 60 | 盘中轮询间隔(秒)。实际周期 = 每轮取数+计算耗时 + 本值(每轮结束 `time.sleep(POLL_SECONDS)`,`tq_alert_top10.py:553`) |
| `POLL_BARS` | 3 | 轮询每次取最近几根日K(含今日盘中实时 bar) |
| `FULL_RESCAN_MINUTES` | 0 | 全市场重扫间隔(分钟),0=关闭;>0 时每隔 N 分钟重跑启动扫描更新候选池(全量重扫耗时约 30~90 分钟,**期间轮询暂停**) |
| `INDEX_REFRESH_PER_POLL` | False | 每轮轮询是否刷新上证指数大盘状态;False=沿用盘前状态(信号 1/5/15/27/39/47 依赖大盘空头、TQ52 依赖大盘多头,盘中大盘状态变化时需置 True 才能及时提醒) |
| `WARN_BATCH` | 100 | 单次 send_warn 最大条数(超出分批发送) |

### 4.2 启动流程

出处:`tq_alert_top10.py:429-507`(main)。

1. **股票池**:`tq.get_stock_list("50")` 取沪深A股(失败降级 market="5"),经 `_clean_stock_list` 归一化去重,剔除科创板/北交所/基金/ST;
2. **大盘状态**:取上证指数 999999.SH 日线,计算大盘空头/多头(`_get_index_state`,`tq_confirm_top10.py:785-807`);
3. **启动扫描**:全市场分批(每批 `CHUNK_SIZE=100`)取 300 根日K,与盘后扫描同口径,约 30~90 分钟(`_startup_scan`,`tq_alert_top10.py:248-265`);单批失败跳过续跑;
4. **构建候选池**(`_build_pool`,`tq_alert_top10.py:268-314`):
   - 信号**已触发**(任一信号为真)→ 直接入池,记入启动提醒列表;
   - 信号**近触发** → 入池:3 个子条件的组合 ≥2 个为真;2 个条件的组合(51~57)≥1 个为真,其中「组合11」子条件按窗口子条件(缠论买点4日/六红4日)任一为真即算真(`_sub_true`,`tq_alert_top10.py:195-200`;子条件映射表 `COMBO_SUB`,`tq_alert_top10.py:96-154`);
   - 上证指数缺失时,含「大盘空头成立」的组合(1/5/15/27/39/47)按其余 2 个非指数子条件**全真**才入池;TQ52 的「卖52形态」在指数缺失时恒为假(只能靠组合11 子条件入池);
   - 不足 `MIN_BARS=250` 根K的个股(次新股/长期停牌/数据缺失)跳过;
5. **启动提醒**:启动扫描时已触发的信号,立即发一轮预警(发送通路与盘中一致,见第六节)。

> 默认候选池为盘前快照(`FULL_RESCAN_MINUTES=0` 不盘中更新);盘中新出现近触发的股票需开启全市场重扫才会入池。

### 4.3 盘中轮询

出处:`_poll_once`,`tq_alert_top10.py:376-425`;主循环 `tq_alert_top10.py:509-556`。

1. 每轮对候选池分批取最近 `POLL_BARS` 根日K(含今日盘中实时 bar);
2. `_merge_history`(`tq_alert_top10.py:203-219`)把新取K线**按日期索引合并**进启动时的历史缓存:同日重复以最新取回值覆盖(当日盘中实时 bar 覆盖旧的当日bar)、NaN 行丢弃(防止覆盖历史有效K线)、索引归一化到「日」、截断保留最近 300 根——保证 MA233 等长周期指标预热不受影响,信号口径与盘后扫描一致;
3. 重算全部 57 信号(组合11 事件前提与盘后扫描同口径,`tq_confirm_top10.py:283-555` + `compute_chanlun_liumai`);
4. 收集「信号为真且当日未提醒过」的新触发 → 发预警 + 汇总(见第六节);
5. **交易时段判断**(`_in_trading_session`,`tq_alert_top10.py:158-166`):周一至五 9:30-11:30、13:00-15:00(本机本地时间)之外打印「非交易时段,休眠中」并休眠;不判断法定节假日(节假日客户端无实时行情,轮询自然无新触发);
6. 可选:全市场重扫(`tq_alert_top10.py:520-540`)——`FULL_RESCAN_MINUTES>0` 时周期重跑启动扫描,候选池只增不减,重扫发现的新触发立即发「重扫提醒」;
7. 可选:每轮刷新上证指数(`tq_alert_top10.py:541-547`)——`INDEX_REFRESH_PER_POLL=True` 时每轮重取指数更新大盘状态,刷新失败沿用上次状态;
8. 容错:单票/单批取数或计算失败跳过续跑;轮询异常打印后 60 秒继续(`tq_alert_top10.py:554-556`)。

## 五、去重规则

出处:`_AlertBook`,`tq_alert_top10.py:169-192`;标记时点 `tq_alert_top10.py:340-348`。

1. 当日已提醒集合以 **(日期, 代码, 信号号)** 三元组为键,内存集合去重;
2. **每信号每股票每日只提醒一次**;
3. **跨日自动重置**:轮询时检测日期变化即清空集合(`_check_day`,`tq_alert_top10.py:175-181`);
4. **仅发送成功的条目**才写入已提醒集合;发送失败的条目**下一轮自动重试**(`tq_alert_top10.py:340-342, 347-348`);
5. **不撤回**:盘中信号提醒后若行情回落、信号变回不成立,当日不会重复提醒,也不会撤回已发预警(信号为「最新一根日K」状态型,盘中实时 bar 未收盘,属正常现象)——请自行结合盘面判断。

## 六、预警出口

三个出口,由 `_make_row`(`tq_alert_top10.py:222-244`)、`_send_rows`(`tq_alert_top10.py:318-349`)、`_send_summary`(`tq_alert_top10.py:352-372`)实现:

| 出口 | 通道 | 内容 |
|------|------|------|
| 个股界面预警 | `tq.send_warn` | 触发瞬间逐条发送到**客户端个股界面**;字段:stock(代码)、time(YYYYMMDDHHMMSS)、price/close(最新价,2 位小数)、volum(成交量)、bs_flag(买入=0、卖出=1)、warn_type=0、reason(带排名序号的信号名,如「TQ27 二次涨停+大盘空头+深跌」,≤25 字,压缩表见 `tq_confirm_top10.py:200-229`);单次最多 `WARN_BATCH=100` 条,超出自动分批 |
| 策略界面汇总 | `tq.send_message` | 每轮新触发汇总发到 **TQ 策略界面**,分「买入信号」「卖出信号」两段,每条带序号与代码列表(每信号最多列 8 只,超出记"(共N只)") |
| 运行终端 | stdout | 全部明细:每条预警的时间/代码/信号名/最新价/成交量(带买卖方向),以及每轮轮询统计(取数只数/失败数/新触发条数/当日累计已提醒条数) |
