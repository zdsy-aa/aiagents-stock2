## 已知问题

> 条目从 Phase 1~5 账本 deferred 与终审记录提炼,逐条注明来源与 2026-09-28 复验结果。

1. **盈亏比无下行收益**:确认面板「区间涨跌幅」= ext_up(未来 20 日最高价/收盘-1,上行口径),亏损侧无真实负收益可统计;整表报告 57 信号「盈亏比」全为 ∞、「涨跌占比」全为「—」(report.py 注释:「引擎在测试段无负收益亏损行时输出 inf」)。来源:Phase 3 终审/Phase 4 记账;复验:report/回测报告_57信号_20260927_123206.md。
2. **筹码数据源不可用**:三源探测——akshare(东财 IP 封禁)、tdx_file(缺换手率/流通股本)、本地无通达信客户端——结论 source=unavailable;`chip_decision()` 返回 unavailable,`fetch_chip` 抛 NotImplementedError,东财解封后改 automation/chip_data.py 的 `_DECISION` 即启用(akshare 映射已实现并有单测)。来源:Phase 5.5 选型结论(docs/chip_data_decision.md)。
3. **venv-data 缺部分三方库**:pyarrow/streamlit/yfinance/sqlalchemy 未装(2026-09-28 实测 import 失败);akshare 已由 Phase 5.5 经清华镜像装好;主应用与部分功能需补齐依赖才能跑。来源:Phase 5.5 探测日志 + 本任务实测。
4. **分析每股双记录**:单股分析落库存在两条记录——stock_analysis_engine 直写(无版本字段)与 ai_trace.trace_save(带 prompt_version/model_version/input_snapshot);comparison_table 按 (代码, analysis_id) 去重、版本化记录优先(P5-1 方案 B),待引擎单点化收口。来源:Phase 4 记账/Phase 5 前置项 P5-1(interfaces/ai_trace.py 头部注释)。
5. **TDX 客户端未在 Linux 安装**:57 信号盘后扫描/盘中提醒(通达信py脚本 5 个)运行于 Windows 侧通达信客户端,本机 Linux 无法执行;Linux 侧经 backtest/signal_specs.py + interfaces/screen.py 重新实现。来源:Phase 5.5 探测(「本机为 Linux,无通达信客户端」)+ Phase 1 ASSETS.md 1.2。
6. **registry 未支持函数 8 个**:WINNER(28 处,威科夫体系)/NAMELIKE/FINANCE/DYNAINFO/HHVBARS/LLVBARS/SUMBARS/DMA 求值期抛 NotImplementedError,威科夫体系「获利盘/活跃筹码/套牢盘/筹码集中/筹码锁定」5 个输出不可求值(registry.json「核心_基础V3」partial/unsupported 登记)。来源:Phase 2(indicators/tdx_builtins.py 头部登记)。
7. **买点事件面板截至 2026-05-28**:signal_features.csv + turnover_signal.csv 合表 97,329 行,最新信号日期 2026-05-28,测试段 2026 年仅 1,356 行(2025 年 10,275 行);确认面板(15.1M 行)覆盖至 2026-08-05、v2 至 2026-09-07,两个面板行集/口径不同,消费方须按 dataio 注释区分。来源:Phase 3;2026-09-28 实测面板统计。
8. **registry 覆盖率不足**:32 个公式文件仅 3 条注册(完全可求值 4/部分 20/不可求值 8),WINNER 等 8 个函数未支持,威科夫体系整体待函数扩展后入库(Phase 2 结论)。复验(2026-09-28):registry.json 当前 3 项——六脉神剑V5(15 输出)、核心_基础V3(40 输出,partial=True,5 输出不可求值,见第 6 条)、MACD(3 输出),合计 58 输出;其余 29 个公式文件未注册,registry_overrides.json 为空。
